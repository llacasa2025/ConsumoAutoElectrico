# requisito: 
Crear una aplicacion  llamada ConsumoAutoElectrico, se ejecuta en local, los datos tienen que quedar persistentes, NO se pueden perder.

#Tecnologia
Usaremos javascipt, CSS y HTML. El lenguaje de interaccion tiene que ser españ

#Versionado
Usaremos GIT y GITHUB, para guardar cada vez que hagamos una modificacion.

#Funcionamiento
La aplicacion tiene que pedir el kilometraje actual, la carga en KW, el costo de la carga, el costo de la conexion y el IVA

#Seguridad
Si tienes dudas preguntas, antes de guardas los cambios mostrame las modificaciones y yo y solamente yo te dire cuando aprobar los cambios
